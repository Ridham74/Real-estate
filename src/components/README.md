# Components Directory Structure

This folder will house modular, reusable components for HomeConnect:

- `layout/`: Navbar, Footer, MobileNav, Containers
- `home/`: Hero, SearchBar, PropertyCategories, FeaturedProperties, PopularCities, WhyChooseUs, CTA
- `ui/`: Buttons, Badges, Cards, Modal, Input fields
- `auth/`: Richa AI Login and Sign Up modal/forms
